## 3. Key Themes

**1. Canvas alone isn't enough, but people patch it differently.**
Most students layer something onto Canvas — a browser extension (Better Canvas/BetterCampus), a Google Doc, a Notes app, a paper list, or an Outlook calendar — because Canvas doesn't surface *study* tasks, only posted assignments.

**2. Time estimation is the most common — and most painful — friction point.**
Several interviewees (Breanna, Navya Int3, Kyle, Aslidin, Ibrohim) explicitly struggle to predict how long a task will take, which drives postponement and, in some cases, missed work. This is the clearest validation of AllocateCanvas's core value proposition.

**3. Reactions split into three groups:**
- **Strong fits:** Breanna, Haley, Saurav — each has an unmet planning/estimation need the tool directly addresses.
- **Soft fits:** Sri, MJ Int3, Aslidin, Ibrohim — positive but not core problem-havers; often more excited by *resource surfacing* than time-blocking.
- **Skeptics/non-adopters:** Kyle, MJ Int2, Navya Int2 (implied) — already have a working system (Better Canvas, extensions) they're attached to.

**4. "Study material Canvas never posts" resonates strongly.**
Multiple students (Saurav, Breanna, Ibrohim) independently flagged the lack of a centralized place for study/exam prep — directly validating the extension's core pitch.

**5. Missed assignments cluster around a few causes:**
- Forgotten/overlooked small assignments while focused on bigger ones (Aslidin, Ibrohim)
- Due-date vs. due-*time* confusion (Haley)
- Lack of reminders (Navya Int4)
- Underlying focus/attention challenges (Breanna)
- Difficulty/ambiguous deadlines handled via professor emails, not planning failures (Sri, Saurav)

**6. Requested features worth prioritizing:**
- Dynamic/automatic rescheduling of time blocks when plans shift (Saurav)
- A priority hierarchy that flags immovable deadlines when a block is moved (Saurav)
- Reminders to *start* studying before an exam, not just when something is due (Ibrohim, Himel's interviews)
- Surfacing buried/hard-to-find module content directly into a calendar (Sri)
- Customizable/tailored task logging to avoid skewed time averages (Breanna)
